---
description: Flujo guiado para construir una feature nueva de punta a punta
---
1. Haz hasta 3 preguntas para aclarar el objetivo, los usuarios y los casos borde. Espera mis respuestas.
2. Propón un plan corto: modelo de datos, endpoints (con request/response), pantallas y tests. Espera mi aprobación.
3. Implementa en este orden: migración y modelo (`database-design`) → backend (`backend-python`) → frontend (`frontend-react`).
4. Escribe los tests de cada capa a medida que avanzas.
5. Ejecuta el workflow `/review` y presenta el informe final.
